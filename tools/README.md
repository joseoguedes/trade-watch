# Holiday data tools

`Tradewatch/holidays.json` (holiday closures with names + early closes for every
exchange) is generated by `build_holidays.py`:

    python -m venv .venv
    .venv/Scripts/python -m pip install exchange_calendars holidays
    .venv/Scripts/python tools/build_holidays.py Tradewatch/holidays.json

Sources:
- [exchange_calendars](https://github.com/gerrymanoim/exchange_calendars) — real trading
  calendars (closures + early closes) for ~60 exchanges.
- [holidays](https://github.com/vacanza/holidays) — country public holidays: English
  names for every exchange, and the closure list for the ~40 exchanges
  exchange_calendars doesn't cover. That part is an approximation (exchanges can close
  on extra days; Islamic dates are moon-sighting estimates).

Hand-maintained bits at the top of the script:
- `MANUAL_2027` / `MANUAL_EARLY_2027` — 2027 for SGX (official), India and China
  (ESTIMATES: replace when NSE's circular / China's State Council schedule come out,
  usually Nov–Dec).
- `EXTRA_CLOSURES` — library bugs (Baltic exchanges' Christmas Day 2026).
- Sri Lanka 2027 is empty until its holidays are gazetted; re-run then.

When adding an exchange to the app, add it to `EXCHANGES` too (with the same weekend days).
